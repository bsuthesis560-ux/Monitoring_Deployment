1. Overview

Integrate the existing facial recognition system into the web-based personnel monitoring system to automate attendance logging. The system must enforce strict department-based data isolation and ensure accurate, continuous attendance tracking.

2. Core Concept
Admin registers personnel with facial images.
The system extracts and stores face embeddings.
When detected via camera:
The system identifies the person
Automatically logs attendance
3. Registration + Face Enrollment
Required Fields:
Full Name
Employee ID
Department (CET, ICT, ADMIN, HR)
Position
Vehicle Plate Number (optional)
Facial Image (required)
Processing:
Detect face
Encode facial features
Store encoding in database
Validation Rules:
Reject if:
No face detected
Multiple faces detected
Ensure clear, front-facing image
4. Facial Recognition Workflow
Camera detects face
System compares with stored embeddings
If matched:
Retrieve personnel data
Proceed to attendance logging
5. Attendance Logging Rules (Continuous Alternating IN/OUT Loop)
Core Behavior

The system must support continuous attendance logging, where each successful recognition alternates between Time IN and Time OUT for the same personnel.

Logging Logic (Alternating Sequence)

For each personnel, within the same day:

1st Detection → Time IN
2nd Detection → Time OUT
3rd Detection → Time IN
4th Detection → Time OUT
Continue alternating for all detections
✅ Example Scenario
08:00 AM → Time IN
12:00 PM → Time OUT
01:00 PM → Time IN
05:00 PM → Time OUT

✔ Pattern continues throughout the day

Technical Logic
IF no record today:
    log = TIME_IN
ELSE IF last log == TIME_IN:
    log = TIME_OUT
ELSE:
    log = TIME_IN
Safeguards
Cooldown (5–10 seconds) to avoid duplicate scans
Logs must be tied to current date
Prevent incorrect rapid alternation
6. Department-Based Enforcement (CRITICAL RULE)
Strict Isolation
Each personnel belongs to one department only
Attendance logs must include department
Visibility Rules

Only selected department data is visible
❗ Strict Restriction
No cross-department visibility
Even Admin cannot view mixed department data
