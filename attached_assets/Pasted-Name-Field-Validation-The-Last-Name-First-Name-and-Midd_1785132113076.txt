Name Field Validation

The Last Name, First Name, and Middle Name fields should only accept alphabetic characters and approved name separators (such as spaces, hyphens, or apostrophes if required). These fields must not accept numbers, special characters, or symbols that are not valid in a person's name.

Additionally, the system should reject empty values, whitespace-only entries, and names that exceed the defined maximum character limit.

Duplicate Employee Validation

Before creating a new employee record, the system must verify whether an employee with the same identity already exists in the database.

For example:

Existing Employee: Christian Lloyd Brito
New Registration Attempt: Christian Lloyd Brito

The system should reject the registration and notify the user that the employee is already registered.

Furthermore, the duplicate validation should be case-insensitive and ignore unnecessary formatting differences. This prevents users from bypassing the duplicate check by changing letter capitalization or formatting, such as:

CHRISTIAN LLOYD BRITO
christian lloyd brito
ChRiStIaN LlOyD BrItO
Christian Lloyd Brito (multiple spaces)

All of the above should be recognized as referring to the same employee.

To improve the accuracy of duplicate detection, the system should normalize the input before comparison by:

Converting all text to a consistent case (e.g., lowercase).
Removing leading and trailing whitespace.
Replacing multiple consecutive spaces with a single space.

If a matching employee record is found after normalization, the system must reject the registration and display an appropriate validation message indicating that the employee already exists.

Recommendation

For a more robust employee management system, consider validating uniqueness using a combination of identifying information rather than relying solely on names. For example, enforce uniqueness based on:

Employee ID (primary unique identifier)
First Name
Middle Name
Last Name
Date of Birth (if applicable)

Using multiple identifiers significantly reduces the possibility of false duplicates while ensuring that the same individual cannot be registered more than once. This approach aligns with industry best practices for maintaining accurate personnel records.
