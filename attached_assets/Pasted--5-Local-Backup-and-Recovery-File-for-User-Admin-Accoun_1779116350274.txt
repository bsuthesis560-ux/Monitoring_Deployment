## 5. Local Backup and Recovery File for User/Admin Accounts

Create a local backup and recovery system for user and admin account credentials.

### Requirements

* Generate a dedicated `.csv` or `.txt` file that stores account credentials for:

  * Admin accounts
  * User accounts

* This file will serve as a backup and recovery reference in cases where users or administrators are unable to log in.

* The backup file must be:

  * Automatically updated whenever accounts are created or modified
  * Stored locally on the system
  * Organized inside its own dedicated folder structure

Example:

```text id="d7v5mx"
/account_backup/
    users_backup.csv
```

This structure should function similarly to the existing dedicated folder used for registered personnel data.

## 6. Downloadable Attendance Summary PDF

The Record Summary module must support exporting attendance summaries into downloadable PDF files.

### PDF Export Requirements

The generated PDF reports should support:

* Daily attendance summaries
* Weekly attendance summaries
* Monthly attendance summaries

The PDF generation must:

* Use the provided template file as the official report format
* Preserve the layout and structure of the template
* Automatically populate:

  * Employee Name
  * Date & Time
  * Department
  * Position
  * Log Type

### Department-Based Separation

PDF summaries must also follow department-based categorization to prevent records from different departments from mixing together.

Example:

* HR Daily Summary
* ICT Weekly Summary
* CET Faculty Monthly Summary

---

### Export Functionality

The system should provide:

* Downloadable PDF generation directly from the Record Summary section
* Proper file naming conventions based on:

  * Record type
  * Department
  * Date range

Example:

```text id="0rpk4y"
HR_DailySummary_May18_2026.pdf
ICT_WeeklySummary_Week3_May2026.pdf
```

The exported PDFs should be clean, properly formatted, and suitable for administrative reporting and documentation purposes.
